# 30days-essence
エクストリームミニマリストになるための欲しいものリスト

# 説明
物価上昇に伴い、生活が苦しくなってきた今日この頃  
もう一度自分に本当に必要なものは何かを見極める必要があると思い、このアプリを作りました。  
ぜひ活用して、本当に必要な物だけで生きてください  

# 技術スタック
フロントエンド  
Next.js（TypeScript）,Tailwind.css   
  
バックエンド  
supabase  
  
デプロイ  
Cloudflare Pages  

# コマンド

```
開発環境 npm run dev
ビルド npm run build
本番環境 npm start
```
